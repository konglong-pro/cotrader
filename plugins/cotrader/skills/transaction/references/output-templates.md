# Transaction Output Templates

Use only the sections needed by the selected mode. Begin with the mode line, then security identity and the conclusion. Keep source links beside material claims, and use the shared blocks below in short modes instead of repeating a full report. Unknown fields must not force a classification or invented risk; a user-requested format can replace these layouts while preserving evidence and limitations.

## Shared Evidence And Hypothesis Blocks

```text
研究日期/窗口：
信息截止（北京时间）/ 行情观测时点 / 分析时间：
证据：ID | 事实/数值 | 原始来源链接与等级 | 披露/数据时间 | 单位/期间 | 核验状态
假设：ID | 判断与窗口 | 支持证据 ID | 最强反证/替代解释 | 区分信号 | 置信度理由
传导：催化 -> 业务暴露 -> 收入/成本/现金流影响 -> 时间与约束
下一核验：指标或事件 | 比较基准 | 来源 | 未来窗口 | 确认/失效条件
```

Separate confidence in facts from confidence in causal attribution or continuation. Use “无法判断” for insufficient price/catalyst data. “未见明显反应” requires current comparable observations and does not prove underpricing.

## Hypothesis Follow-Up

Use for a follow-up or within an after-hours review when an original hypothesis exists:

```text
当前使用模式：假设验证复盘
研究窗口 / 原信息截止 / 本次信息截止：
原假设 ID 与摘要 | 原验证/失效条件 | 新证据 ID | 实际观测 | 支持/弱化/失效/待验证 | 修正理由与下一核验
误差来源：数据缺口 / 归因错误 / 市场环境变化（按证据选择）
```

If the original record is unavailable, state “无原始假设记录，仅做事后归因.” Do not invent the original forecast, claim a hit rate, or mark missing observations as invalidation.
